# 스킬 카드 목록

총 **63장** · 코스트 1~8

## 카드 유형

| 유형 | 설명 |
|---|---|
| **일반** | 사용하면 그 턴에 기물을 움직일 수 없음 |
| **속공** | 코스트만 있으면 다른 카드와 함께 사용 가능. 기물도 움직일 수 있음 |
| **부여** | 내 기물 또는 적 기물에 효과를 부여. 사용하면 그 턴 종료 |
| **지속** | 파괴되기 전까지 효과가 유지됨. 처음 사용한 턴은 종료 |
| **대응** | 패에 든 상태에서 상대 행동에 반응해 발동. 소모할 코스트를 남겨둬야 함 |

## 대응 카드 처리 규칙

- 대응 카드는 **"한 턴에 스킬 카드 1장"** 제한에 걸리지 않음. 상대 턴에 사용하므로 내 턴의 사용 횟수와 별개로 계산함
- 체인 길이에 제한 없음. **남은 코스트가 되는 한 계속 이어갈 수 있음**
- 체인은 **나중에 낸 카드부터 역순으로 해결**함
- 무효화된 카드는 **파괴된 것으로 처리**함 (전령·회수로 되살릴 수 있음)
- 무효화당해도 **이미 지불한 코스트는 환불되지 않음**
- 받아치기로 훔친 효과는 **주체가 뒤바뀜**. 예를 들어 상대의 강제(상대 패 2장을 덱으로)를 받아치면, 상대의 패 2장이 덱으로 돌아감

## 1 코스트 (10장)

| 카드명 | 유형 | 효과 |
|---|---|---|
| 정찰 | 속공 | 상대 패 1장을 선택해 어떤 카드인지 확인 |
| 밀정 | 속공 | 상대 덱 맨 위 1장을 확인 |
| 점술 | 속공 | 내 덱 맨 위 3장을 보고 원하는 순서로 되돌림 |
| 명상 | 속공 | 카드 2장 드로우 (패 5장 초과 불가) |
| 헌납 | 속공 | 패에서 다른 카드 1장을 버리고 2장 드로우 |
| 위장 | 속공 | 패에서 최대 2장을 덱에 넣고 셔플. 넣은 장수만큼 드로우 |
| 준비 태세 | 속공 | 이번 턴 코스트 +2 |
| 미끼 | 부여 | 내 폰 1개에 미끼 토큰 부여. 이 폰이 파괴되면 2장 드로우 |
| 작은 모래주머니 | 부여 | 적 기물 1개에 모래주머니 토큰 부여. 자신 턴 기준 **2턴** 지속 (킹 제외) |
| 경계 | 대응 | 상대가 카드를 사용하면 1장 드로우 |

### 모래주머니 토큰 공통 효과

| 대상 | 제약 |
|---|---|
| 퀸 · 비숍 · 룩 | 최대 2칸까지만 이동 가능 |
| 나이트 | 뛰어넘기 불가 |
| 폰 | 이동 불가 |
| 킹 | 부여 대상이 아님 |

## 2 코스트 (6장)

| 카드명 | 유형 | 효과 |
|---|---|---|
| 질주 | 속공 | 내 기물 1개를 한 칸 이동. 공격 불가 (적 기물을 잡을 수 없음) |
| 밀쳐내기 | 일반 | 내 기물과 인접한 적 기물 1개를 반대 방향으로 1칸 밀어냄<br>└ 밀려날 칸에 다른 기물이 있거나 판 밖이면, 그 기물은 대상으로 지정할 수 없음 |
| 끌어당기기 | 일반 | 내 기물과 같은 직선상에 있는 적 기물 1개를 내 기물 바로 앞 칸으로 끌어옴<br>└ 그 칸이 비어 있지 않거나 경로가 막혀 있으면, 그 기물은 대상으로 지정할 수 없음 |
| 도약 | 부여 | 내 폰 1개에 부여. 자신 턴 기준 3턴간 다른 기물을 뛰어넘어 이동 가능 |
| 늪지 | 지속 | 빈 칸 1개를 지정. 그 칸에 들어온 기물은 다음 턴 이동 불가 |
| 작은 방패 | 대응 | 내 **폰**을 대상으로 한 적의 공격을 1회 무효화 |

## 3 코스트 (8장)

| 카드명 | 유형 | 효과 |
|---|---|---|
| 천리안 | 속공 | 상대 패를 전부 확인 |
| 전령 | 속공 | 파괴되었거나 사용한 카드 1장을 골라 덱에 넣고 셔플 |
| 투창 | 일반 | 내 킹과 인접한 1칸 내 폰을 던짐. 던진 방향 일직선상의 적 1개를 파괴하고, 던진 폰도 파괴 |
| 성채 | 일반 | 조건을 무시하고 캐슬링을 즉시 실행 |
| 큰 모래주머니 | 부여 | 적 기물 1개에 모래주머니 토큰 부여. 자신 턴 기준 **5턴** 지속 (킹 제외) |
| 봉화 | 지속 | 내 기물이 파괴될 때마다 1장 드로우 |
| 간파 | 대응 | 상대가 사용한 **속공 또는 대응** 카드 1장을 무효화 |
| 방어 | 대응 | 내 기물이 지형 효과(늪지·지뢰 등)의 대상이 될 때 1회 무효화 |

## 4 코스트 (12장)

| 카드명 | 유형 | 효과 |
|---|---|---|
| 해주 | 속공 | 부여마법에 걸린 **내** 기물 1개의 부여를 해제 |
| 해금 | 속공 | 부여마법에 걸린 **적** 기물 1개의 부여를 해제 |
| 회수 | 속공 | 파괴되었거나 사용한 카드 1장을 패로 회수 |
| 강제 | 속공 | 상대 패에서 2장을 선택해 덱으로 되돌림 |
| 전환 | 일반 | 킹을 제외한 내 기물 2개의 위치를 서로 교환 |
| 위병 훈련 | 부여 | 내 폰 1개에 부여. 이동 제약 없이 1칸 이내 어디로든 이동 가능하며, 적을 잡는 것도 가능 |
| 무장해제 | 부여 | 적 기물 1개에 부여. 상대 턴 기준 5턴간 다른 기물을 잡을 수 없음 (이동은 가능) |
| 지뢰 | 부여 | 빈 칸 1개에 비공개로 설치. 적 기물이 밟으면 파괴됨 (킹은 파괴되지 않고 이동만 취소) |
| 환각 | 지속 | **상대 플레이어**에게 부여. 자신 턴 기준 5턴간 상대에게는 모든 기물이 폰으로 보임 |
| 첩보 | 지속 | 상대가 카드를 드로우할 때마다 주사위를 굴림. **4·5·6**이 나오면 그 카드를 확인 |
| 회피 | 대응 | 공격당한 내 기물을 인접한 빈 칸으로 랜덤 도피. 공격한 적 기물은 원래 목표 칸으로 이동함 |
| 끊어내기 | 대응 | 상대가 부여 카드를 사용할 때 발동. 내 기물을 대상으로 한 부여를 무효화 |

## 5 코스트 (9장)

| 카드명 | 유형 | 효과 |
|---|---|---|
| 더블 | 속공 | 이번 턴 지정한 기물을 두 번 움직일 수 있음 |
| 희생의 대가 | 속공 | 킹·폰을 제외한 내 기물 1개를 파괴하고, 내 기물 3개를 이동. 공격 불가 |
| 승진 | 일반 | 내 폰 1개를 나이트 · 룩 · 비숍 중 하나로 즉시 승격 |
| 분신 | 일반 | 옆칸이 비어 있는 내 기물(킹 제외)의 분신을 그 칸에 소환. 자신 턴 기준 5턴간 유지 |
| 비장의 한방 | 일반 | 내 킹 주변 3×3 안의 적 기물 1개를 암살(적 킹 제외). 킹이 그 위치로 이동함 |
| 무르기 | 일반 | 상대의 직전 턴 움직임을 무효화. 상대는 다음 한 턴 동안 그 기물을 움직일 수 없음 |
| 절약 | 지속 | 이후 내가 사용하는 모든 카드의 코스트 −1 (최소 1, 0은 불가) |
| 받아치기 | 대응 | 상대가 사용한 **속공** 카드를 무효화하고, 그 효과를 내가 대신 발동 (발동하지 않아도 됨) |
| 최후의 저항 | 대응 | 내 킹이 체크메이트가 될 때, 킹을 임의의 빈 칸으로 순간이동 |

## 6 코스트 (9장)

| 카드명 | 유형 | 효과 |
|---|---|---|
| 파괴 | 속공 | 발동 중인 지속 카드 1장, 또는 상대 패 1장을 선택해 파괴 |
| 교환 | 속공 | 내 패 1장과 상대 패 1장을 교환 |
| 각성 | 일반 | 킹·퀸을 제외한 내 기물 1개를 자신 턴 기준 5턴간 퀸으로 승격 |
| 세뇌 | 부여 | 상대 폰을 최대 3개까지 선택해 즉시 내 폰으로 전환. 부여가 해제되면 원래대로 복귀 |
| 동맹사슬 | 부여 | 내 기물 1개와 적 기물 1개를 연결. 연결된 둘은 서로 공격할 수 없음<br>└ 어느 한쪽에 연결된 기물만 남으면 효력이 정지되고, 새 기물이 생기면 다시 발동 |
| 운명의 사슬 | 부여 | 내 기물 1개와 적 기물 1개를 연결. 하나가 파괴되면 다른 하나도 함께 파괴 |
| 민첩한 나이트 | 지속 | 내 나이트가 장기의 상(象)처럼 이동 가능 |
| 흙탕물 | 지속 | 상대가 카드를 사용할 때 필요한 코스트를 모두 +1 |
| 보디가드 | 대응 | 내 킹이 공격당할 때, 다른 기물 1개를 대신 파괴하고 킹을 그 위치로 이동 |

## 변경 이력

### 이번 수정

- **간파** — 대상을 `속공` → `속공 또는 대응`으로 확대. 받아치기를 막을 수단이 없던 문제 해결
- **받아치기** — 속공 전용 유지. 대응까지 훔치면 대상 지정이 꼬이므로 범위를 넓히지 않음
- **대응 체인 규칙** 신설 (문서 상단)
- **밀쳐내기 / 끌어당기기** — 목적지가 막혔거나 판 밖이면 대상 지정 자체가 불가하도록 명시
- **환각** — 지속 유지(상대 플레이어에게 직접 거는 카드이므로), 지속 시간 4턴 → **5턴**
- **여왕암살** — 8코 → **7코**

### 오타 · 문구 수정

- 질주 `먹지는 목함` → 잡을 수 없음
- 지뢰 `밝을 시` → 밟을 시
- 보디가드 `죽게히고` → 대신 파괴하고
- 끊어내기 `사용할떄` → 사용할 때
- 간파 `무효함` → 무효화
- 회피 `공격한 위치로 오긴함` → 원래 목표 칸으로 이동함
- 밀쳐내기 `1칸이내 인접한` → 인접한 (중복 표현)
- 역병 `그 턴 대상자의 폰` → 자신의 폰 (주체 명시)
- 도약 `내 기준 3턴간` → 자신 턴 기준 3턴간 (표기 통일)
- 모래주머니 제약 표를 공통 항목으로 분리
